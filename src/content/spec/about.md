本站基于 **Astro** 框架构建，使用了 [Mizuki](https://github.com/LyraVoid/Mizuki) 主题。

::github{repo="LyraVoid/Mizuki"}

## 🌟 主题特性

### 🎨 设计与用户体验
- **现代且优雅的设计** - 干净、极简的界面搭配精美的排版
- **完美响应式** - 针对从手机到桌面端的所有设备进行了优化
- **深色/浅色模式** - 自动切换主题，并配有平滑的过渡动画
- **精美的排版** - 使用 JetBrains Mono 字体，提升阅读体验
- **流畅的动画** - 丝滑的页面切换与交互元素

### 🔍 内容与搜索
- **高级搜索** - 由 [Pagefind](https://pagefind.app/) 强力驱动，提供快速、准确的搜索结果
- **增强的 Markdown** - 扩展语法，支持代码高亮和数学公式
- **交互式目录** - 针对长篇文章的自动滚动导航
- **RSS 订阅生成** - 自动生成订阅源，方便读者随时关注
- **阅读时间估算** - 预估文章需要多长时间读完
- **文章分类** - 使用标签和分类来整理内容


### 📱 特色页面
- **番剧追踪页** - 追踪你的看番进度并进行打分
- **友情链接页** - 使用精美的卡片展示朋友们的网站
- **日记/动态页** - 像社交媒体一样分享生活点滴
- **归档页** - 以时间线形式展示所有文章
- **关于页** - 可自定义的个人介绍（即本页面！）

### 🛠 技术特性
- **增强的代码块** - 由 [Expressive Code](https://expressive-code.com/) 强力驱动
- **数学支持** - 使用 KaTeX 渲染 LaTeX 数学表达式
- **图片优化** - 支持 PhotoSwipe 画廊与懒加载
- **SEO 优化** - 内置网站地图和 meta 标签，提升搜索可见度
- **性能优化** - 通过缓存和优化实现快速加载
- **评论系统就绪** - 支持集成 Twikoo 评论

### 🎯 高级 Markdown 特性
- **提示框与警告框** - 使用 `> [!NOTE]`、`> [!TIP]`、`> [!WARNING]` 创建精美的信息框
- **数学公式** - 使用 `$inline$` 和 `$$block$$` 语法编写 LaTeX 数学公式
- **GitHub 卡片** - 使用 `::github{repo="user/repo"}` 嵌入代码仓库卡片
- **语法高亮** - 带有行号的高级代码高亮
- **代码复制按钮** - 便捷的代码一键复制功能
